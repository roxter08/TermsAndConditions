# `1. About this policy` 

```
3D Coloring Adventure is a creative colouring game mainly designed for children
aged 5 to 13.
At Keya Technologies, we understand that children’s privacy is especially
important. This Privacy
Policy explains what information may be collected when someone plays our game
and how it may be
used.
```

```
Parents and guardians are encouraged to read this policy.
```

```
2. Information we do not collect
```

```
The game does not ask players to create an account or provide personal details.
We do not knowingly collect:
```

- `Names, email addresses or phone numbers` 

- `Home addresses or precise locations` 

- `Photographs, videos or voice recordings` 

- `Passwords or account details` 

- `Contact lists` 

- `Payment or banking information` 

- `Messages or other user-created communication` 

```
The game does not include public chat or features that allow children to
communicate with
strangers.
```

```
3. Analytics and technical information
We may use analytics services, such as Google Firebase Analytics, to understand
how the game is
```

```
being used and to improve its performance.
```

```
These services may automatically collect limited information, such as:
```

```
• Game features or colouring objects used
```

- `Session length and general gameplay activity` 

- `App crashes, errors and loading times` 

- `Device type and operating system` 

- `App version` 

- `General region, such as country` 

- `A temporary or app-based device identifier` 

```
We use this information to find technical problems, understand which features
are useful and
improve the game. We do not use analytics information to identify a child by
name or contact them.
Some information may be processed by our analytics provider on our behalf and
may be stored in
another country.
4. Advertising
```

```
The game displays advertisements to help us keep the game available.
Because the game is designed for children:
```

```
• We aim to show only non-personalised and age-appropriate advertisements.
• Advertisements should not be selected using a child’s interests or activity
across different
apps or websites.
```

```
• Advertisements should be clearly separate from the game’s colouring tools and
content.
• We do not knowingly allow advertising for adult content, gambling, alcohol,
tobacco, dating
services or unsuitable violence.
```

```
• Where required, we use advertising services approved for child-directed apps.
Advertising providers may automatically receive limited technical information
needed to display,
```

```
measure and prevent misuse of advertisements. This may include the device type,
operating system,
approximate region, app activity and basic network information.
```

```
We do not give advertisers a player’s name, email address or other details
directly provided by the
```

```
player because the game does not request these details.
```

`5. How information is used` 

```
Limited analytics and technical information may be used to:
```

- `Operate and maintain the game` 

- `Fix crashes, errors and performance problems` 

- `Improve colouring tools, objects and game features` 

- `Understand general usage patterns` 

- `Display and measure non-personalised advertisements` 

- `Protect the game against fraud or technical misuse` 

- `Meet legal and app-store requirements We do not sell children’s personal information.`

7. Children’s privacy
We design the game with children’s safety and privacy in mind. We try to collect
as little information
as possible and do not knowingly request personal information from children.
If we learn that personal information from a child has been collected in a way
that should not have
happened, we will take reasonable steps to remove it.
A parent or guardian may contact us to ask about information connected with
their child or request
its deletion. Because the game does not require an account, we may need limited
device or app
information to locate the relevant data.

needed to operate, study
```

```

combined into
